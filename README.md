# Pokemon Legends Combat

Downloads for Pokemon Legends Combat, a free, accessible client for
Pokémon Showdown, made for blind and visually impaired players.

- **Android:** works with TalkBack. Ordinary screens, no special gestures.
- **Windows:** works with NVDA, JAWS and Narrator, with keyboard shortcuts
  for everything.
- Every battle event has a sound, and battle lines are spoken as they
  happen.

## Download

No release yet. The first one will be Random Battle singles. It will
appear under Releases on this page as an APK file for Android, and a
download for Windows.

## Installing the Android APK

1. Download the APK from the latest release on your phone.
2. Open it. Android asks you to allow installing apps from your browser
   or file manager the first time; allow it.
3. Install, then open Pokemon Legends Combat.

## Your account

You log in with your own Pokémon Showdown account. Your password goes only
to Showdown's own login page. The app never plays by itself: every choice
in a battle is yours.

Pokemon Legends Combat is a fan-made client and is not affiliated with
Pokémon Showdown, Smogon, Nintendo, Game Freak or The Pokémon Company.
